# 全局主题合并

分类已经完整完成，当前 classification.topics 是各主题的结构化分析产物。根据语义合并同义话题，保留不同立场、长尾问题、来源差异与限制。不能仅因为讨论量少就删除某一主题，也不能以最早一批的六个主题作为固定目录。

调用 create_danmaku_report，传原 evidence_id 和 merge_json，不再传 topics_json。merge_json 是数组，每项包括：

- title：具体讨论主题，最长80字符。
- observation：整合后的反馈，最长600字符；保留赞美、疑问、建议、争议的区别，不自行填数字。
- recommendation：具体下一步，最长600字符；无依据时可为空。
- topic_keys：本次归入该主题的全部既有键，例如 ["T1","T8"]。
- 可选 video_context、video_at_ms：说明与已取得视频画面的关系，只用真实采样位置。`video_at_ms` 必须是整数数组（例如 `[1320]`），最多4个；单个整数无效。

所有既有主题键必须恰好出现一次，不得遗漏、重复或新增未知键。来源不同不必强行拆成两个主题，但观点相反不能在合并时消失。主题最多100个，页面只先展示前六个，其余可展开；不要为了页面简洁丢掉分析结果。作者发言所在主题继续明确其身份，不把作者表达转成观众证据。

已取得视频证据时至少一个最终主题保留有效画面关联。最终正文原话由服务端按主题选择并全局去重，不需要在观察里反复抄原文。工具计算各来源数量并检查全量覆盖，通过后直接交付 HTML，不能另行生成一份缺少原文引用的报告替代它。
