# 视频素材

此目录保存可随仓库拉取的视频原文件，不包含 Trace、验收日志或服务器凭据。

`videos/` 保存服务器数据库中全部 24 个未删除视频的原文件，约 185 MB，按视频 ID 命名。`videos.json` 记录各视频的标题、时长、字节数和 SHA-256 校验值，不包含存储凭据或服务器内部地址。

其余素材的对应关系见 `videos.json`。Windows 示例路径：若仓库位于 `D:\tianmu-keshihua\Tianmu`，素材目录为 `D:\tianmu-keshihua\Tianmu\materials\videos`。

此批素材不包含已删除视频、存储中未关联到视频记录的对象或 Trace 日志。下载仅访问视频数据，没有修改服务器内容。
