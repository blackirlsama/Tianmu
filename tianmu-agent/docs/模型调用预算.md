# 模型调用预算

每个运行任务共享模型调用次数上限。预处理、主循环、收尾、视频视觉及音频转写都占用额度；视频分析缓存命中不占用模型调用。`Snapshot.totalModelCalls` 包含视频与转写调用，`modelCalls` 仍表示主循环调用，`preparationCalls` 仍表示预处理调用。历史快照可以继续读取，不需要修改数据库表。

## Token 预留与结算

`harness.loop.max-tokens`（环境变量 `AGENT_MAX_TOKENS`）为每任务 Token 准入额度，默认 `64000`。调用次数默认16次，可用 `AGENT_MAX_MODEL_CALLS` 配置。显式设置 Token 上限为 `0` 才关闭限制。

`harness.loop.token-reservation`（`AGENT_TOKEN_RESERVATION`）为每次供应商请求的最低预留量，默认 `8192`。文本请求还按实际序列化输入的 UTF-8 字节数、输出 Token 上限及1024 Token协议余量计算保守预留，取两者较大值。字节数不是 Token 的精确估算，宁可提前拒绝，也不按平均字符比例低估大输入。并发分支共享同一本账，发送 HTTP 请求前原子预留。完整有效的 `prompt_tokens` 和 `completion_tokens` 返回后，用实际总量替换预留量；usage 缺失、部分返回、超时、传输异常或非法响应保留预留量，不能当作零消耗。供应商响应中的内容解析失败，也不会抹掉已经上报的 usage。

例如设置 `AGENT_MAX_TOKENS=32768`、`AGENT_TOKEN_RESERVATION=8192`，最多可以同时预留四次小请求；输入较大的请求会占用更多额度。每次完整结算后释放多余预留量。剩余额度不足时，在网络调用前返回 `MODEL_TOKEN_BUDGET_EXCEEDED`；实际结算超额时终止当前任务，不交付该结果。

## 报告复用与提供方配额

报告每批最多40组、12000字符，233组短互动从24个小批次减少为6个批次；长文本会先触及字符上限，批次数可能更多。分类后原文仍在私有证据里，不再发送到后续模型上下文。工具会估算剩余分类及合并的最低调用次数；剩余次数明显不足时返回 `REPORT_BUDGET_INSUFFICIENT`，提前停止后续批次。实际调用次数还包括 Skill 读取、取数、读取视频、合并和重试，受统一预算约束。

报告分类采用最多64项的 Caffeine 热层及可选 MySQL 持久层，结果有效一小时；MySQL 模式支持重启和跨实例复用。相同快照分类使用两分钟计算租约，避免后续批次重复计算。缓存键包含租户、作者、报告请求、视频、完整原文单位（身份、来源、作者标志、回复语境及数量）、视频版本和事实、模型及 Skill/工具指令版本。每次先重新鉴权和取数，再用本次视频证据核对缓存；恢复时重新绑定当前运行的证据 ID。语料、回复、报告关注点或视频改变时重新分析；尚不复用变化语料的增量分区。架构及 Q&A 按阈值加入机制见[缓存与 Q&A 准入](缓存与Q&A准入.md)。

DeepSeek 返回 HTTP 402 时立即停止，并在共享客户端暂停后续请求五分钟；期间不发 HTTP、不预留 Token。402不会触发自动重试，也不会自动启动报告重跑。

这是估算准入控制，不是供应商账单的严格硬上限。视觉、音频和输入文本的实际 Token 可能超过固定预留量，已经发出的并行请求也可能继续产生消耗。应按模型与业务负载调整预留量。当前没有货币价格表或费用结算功能。

## 观察与恢复边界

根 Span 与 finish 节点增加 `budget.token_limit`、`budget.charged_tokens`、`budget.reported_calls` 和 `budget.unsettled_calls`。单次请求记录 `budget.reserved_tokens`；运行汇总包含输入、输出、缓存命中和未命中 Token。失败请求缺失 usage 时，汇总标记 PARTIAL，不能当成免费调用。分类复用记录 `report.cache_hit` 和 `report.reused_groups`。charged 包含完整上报用量和未结算预留，不能称为供应商实际账单；usage 原始统计仍独立保留。

调用次数写入现有任务快照。Token 账本仅属于本次进程内执行，通过任务上下文传播到并发工作线程，不写入模型 Prompt。当前没有在途任务自动重放，因此不支持重启后继续消耗原 Token 额度；未来实现恢复协议时必须一起持久化账本。

验证入口：`mvn -B -ntp -f tianmu-agent/pom.xml verify`。预算测试覆盖并发争用、缺失 usage、传输失败、超额、取消、调用次数与快照恢复；视频适配器测试覆盖发送前拦截和缓存命中不计费。
